KNIGHT SPACE
============

Files
-----
index.html  - The page structure.
style.css   - The game's appearance.
script.js   - The game logic.

How to run
----------
1. Keep all three files in the same folder.
2. Open index.html in a browser.
3. Use the LEFT and RIGHT arrow keys to move.
4. Press SPACE to shoot.
5. Press ENTER to restart after game over.

This is a small learning prototype. It uses original simple shapes,
not copied Subway Surfers or Blastar artwork.
